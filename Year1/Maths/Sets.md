A set is a collection of elements, where
- Order doesn't matter $\{ 0, 1, 2 \} = \{ 2,1,0 \}$
- Repeats don't matter $\{ 0,0,1,2 \} = \{ 0,1,2 \}$
- Two sets are equal $\iff$ All elements of $X =$ All elements of Y 

#### Set comprehension
$\{ x\ |\ P(x) \}$ = the set of things $x$ such that $P(x)$ is true.
$\{ f(x)\ |\ p(x) \}$ = the set of things $x$ such that both functions are true.

#### Set operations
- $x \in X$ means $x$ is a member of set $X$ 
- $X \subset Y$ means x is a subset of Y 
- $|X|$ is cardinality of set $X$ is size of set
- $P(X)$ is **powerset** of $X$ meaning $P(X) = \{ S\ |\ S \subset X \} \} \}$ 
- $X \times Y$ is **product** of $X$ and $Y$ meaning $\{ (x,y)\ |\ x \in X,\ y \in Y \}$

And the boolean operations.

- $X \ \backslash \ A = \{ \ x \in X \ | \ ¬(x \in A) \}$  
- $X\ \triangle\ A = \{ x: (x \in X \ \cap \ x \not\in A) \ or \ (x \not\in X\ \cap \ x \in A) \}$
